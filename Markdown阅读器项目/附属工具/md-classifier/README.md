# Markdown 文件分类器

Windows 本地工具，无需安装 Python 或其他依赖。

## 功能

- 手动添加多个来源文件夹，例如 `D:\data`、`D:\javaCode`。
- 仅扫描这些来源范围内的 `.md` 文件，可选是否包含子文件夹。
- 按创建时间或修改时间筛选起止日期。
- 复制文件到指定目标目录，并按年月、日期或不分目录归集。
- 同名文件自动添加 `(2)`、`(3)`，不会覆盖已有文件。
- 默认只复制，绝不移动或删除原文件。

## 使用

优先双击 `发布\MdClassifier.exe`，添加来源文件夹和目标文件夹后点击“开始复制并分类”。`启动 Markdown 分类器.cmd` 仅作为 PowerShell 备用启动方式。

## 内存占用

工具不会读取 Markdown 正文，只逐个枚举并复制文件。PowerShell + WinForms 空闲时通常约占用 60-120 MB 内存；扫描大量目录时一般额外增加几十 MB，主要取决于 PowerShell、杀毒软件与目录权限响应，而非 Markdown 文件总大小。
