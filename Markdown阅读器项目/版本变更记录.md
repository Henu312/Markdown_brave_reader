# Markdown 浏览器工具版本变更记录

版本规则：`V1` 为只有浏览器插件的初始版本；增加本地服务后进入 `V2`，后续功能均作为 `V2.x` 小版本变更。ZIP 文件编号仅表示打包批次，不代表产品主版本。

## V1：浏览器插件初始版

- 创建 Brave/Chromium Markdown 阅读器扩展。
- 支持点击扩展图标选择 `.md` 文件。
- 支持将 Markdown 文件拖入阅读页面。
- 支持基础 Markdown 渲染：标题、列表、任务列表、引用、表格、代码块、链接和图片。
- 支持深色模式。
- 使用浏览器扩展本地存储恢复最近打开的文档。
- 受浏览器安全限制，不能可靠接管地址栏直接打开的 `file://...md` 下载流程。

## V2.0：增加本地服务

- 增加 Windows 本地 Markdown 启动器。
- 启动器接收 Windows 文件关联传入的 `.md` 路径。
- 在 `127.0.0.1` 启动临时 HTTP 服务，向扩展提供 Markdown 内容。
- 通过本地 HTTP 服务解决扩展页面直接读取 `file://` 时出现的 `Failed to fetch`。
- 支持读取 Markdown 同目录下的相对路径图片。
- 启动器发布为 Windows 自包含程序，不需要 Python、Node.js 或 .NET Runtime。

## V2.1：目录和图片增强

- 根据 `#` 至 `######` 标题自动生成可点击目录。
- 桌面端目录固定在正文左侧，移动端目录移动到正文上方。
- 允许 PNG、JPEG、GIF、WebP 的 Base64 内嵌图片。
- 增加目录标题跳转锚点。

## V2.2：启动器调用扩展

- 启动器从独立阅读器改为打开扩展的 `viewer.html`。
- 使用 `extension-id.txt` 指定目标浏览器中的扩展 ID。
- 通过本地 HTTP 内容接口向扩展传递 Markdown，避免扩展直接读取 `file://`。
- 增加相对路径图片的本地资源接口和 CORS 响应头。

## V2.3：图标

- 增加蓝色文档页和白色 `M` 标识图标。
- 扩展提供 16、32、48、128、256 像素 PNG 图标。
- 启动器 EXE 嵌入 Windows `.ico` 图标。

## V2.4：Chrome 兼容

- 扩展兼容 Brave 和 Google Chrome。
- Manifest 增加 `file:///*`、`http://127.0.0.1/*` 和 `http://localhost/*` 权限。
- 增加 `browser.txt` 配置：`chrome`、`brave`、`auto`。
- 明确 Chrome 和 Brave 可能具有不同的扩展 ID，必须填写当前浏览器的 ID。

## V2.5：编辑模式

- 工具栏增加编辑模式切换按钮。
- 编辑模式采用左侧 Markdown 文本、右侧实时预览布局。
- 支持点击保存按钮或按 `Ctrl+S` 下载 Markdown 副本。
- 默认不直接覆盖原始文件，以符合浏览器文件安全限制。

## V2.6：编辑页面布局优化

- 修复编辑模式下正文和实时预览重复显示的问题。
- 为编辑区和预览区增加独立面板、标题栏、边框和间距。
- 增加 `[hidden] { display: none !important; }`，确保模式切换时只显示当前内容。
- 优化移动端双栏转上下布局的显示效果。

## V2.7：启动器单实例

- 使用命名 Mutex 保证同一时间只有一个 `MdLauncher` 进程。
- 后续打开的 Markdown 文件通过命名管道发送给已有进程。
- 每个 Markdown 文件仍在浏览器中打开独立标签页，但不会继续增加启动器进程。
- 启动器最多运行 2 小时，浏览器进程数量由浏览器自身管理。

## V2.7.1：浏览器配置即时生效

- 每次打开 Markdown 时重新读取 `browser.txt` 和 `extension-id.txt`，修改配置后不再需要重启单实例启动器。
- `extension-id.txt` 支持 `brave=扩展ID`、`chrome=扩展ID` 和 `auto=扩展ID` 配置，同时兼容直接填写单个扩展 ID。
- 明确说明 `chrome-extension://` 是 Chromium 系浏览器共用的扩展协议，不代表固定使用 Chrome。

## V2.7.2：修复编辑模式窄布局

- 修复目录隐藏时正文区域错误占用目录网格列的问题。
- 编辑模式下编辑器和预览区恢复正常的左右双栏宽度，不再按单个字符换行。

## V2.7.3：预览显示开关

- 编辑模式工具栏增加预览显示开关，可在双栏预览和全宽编辑器之间切换。
- 记住用户的预览显示选择，下次进入编辑模式继续使用。

## V2.7.4：修复目录跳转

- 目录链接改为显式定位标题并平滑滚动，兼容扩展页面和不同滚动容器。
- 增加标题滚动偏移，避免跳转后被顶部固定工具栏遮挡。

## V2.7.5：增强目录滚动兼容性

- 改用页面滚动元素的绝对位置执行目录跳转，避免扩展页面中浏览器默认锚点或滚动容器差异导致跳转无效。
- 地址栏锚点更新改为兼容性处理，不影响实际滚动。

## V2.7.6：修复目录标题错位

- 目录和正文使用相同的标题解析逻辑，忽略代码块中的伪标题。
- 修复包含代码块的 Markdown 文档中目录点击跳转到错误标题的问题。

## 当前有效版本

- 扩展 ID 配置：`Markdown阅读器项目\发布\当前版本\md-launcher\extension-id.txt`。
- 推荐发布目录：`Markdown阅读器项目\发布\当前版本`。

## 使用注意

- 更新扩展后需要在 `brave://extensions/` 或 `chrome://extensions/` 点击“重新加载”。
- 双击打开前，需将 `.md` 默认打开方式设置为当前版本的 `MdLauncher.exe`。
- `extension-id.txt` 可直接填写一个扩展 ID，也可按浏览器分别填写 `brave=...`、`chrome=...`。
- 编辑模式保存的是 Markdown 副本，不会默认覆盖原文件。
