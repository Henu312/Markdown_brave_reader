# Markdown 阅读器项目归档

这是本项目相关文件的集中目录。原工作区文件保留在原位置，本目录是可独立备份和维护的归档副本。

## 目录结构

- `源码\brave-markdown-reader`：浏览器扩展源码。
- `源码\md-launcher`：Windows 本地启动器源码、项目文件和配置。
- `源码\icon-generator`：扩展和启动器图标生成源码。
- `附属工具\md-classifier`：Markdown 文件分类器项目。
- `发布\当前版本`：当前推荐扩展、V2.7.4 单实例启动器和配置。
- `发布\当前版本.zip`：当前版本整合包。
- `历史发布`：V4 至 V8 的历史 ZIP 和历史打包目录。
- `示例资料`：用于测试 Markdown 图片嵌入的 README 文件。
- `版本变更记录.md`：V1、V2.x 版本记录。

## 当前维护入口

优先修改 `源码\brave-markdown-reader` 和 `源码\md-launcher`，不要直接修改 `发布` 目录中的副本。修改后重新构建并更新当前发布目录。
