# Markdown 浏览器工具包

扩展兼容 Brave 和 Google Chrome。先在目标浏览器的扩展页开启开发者模式，加载 `brave-markdown-reader`，并开启“允许访问文件网址”。将该浏览器显示的扩展 ID 写入 `md-launcher\extension-id.txt`。

在 `md-launcher\browser.txt` 中填写 `chrome`、`brave` 或 `auto`，然后把 `.md` 默认打开方式设置为 `md-launcher\MdLauncher.exe`。

启动器采用单实例设计：第一次打开文件创建一个 `MdLauncher` 进程，后续打开的 Markdown 文件通过本机命名管道发送给已有进程，不会继续增加启动器进程；每个文件仍会在浏览器中打开独立标签页。

打开 Markdown 后点击铅笔按钮进入编辑模式。左侧编辑、右侧实时预览；点击保存按钮或按 `Ctrl+S` 下载 Markdown 副本。
