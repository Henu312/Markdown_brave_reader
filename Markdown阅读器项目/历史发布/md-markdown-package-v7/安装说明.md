# Markdown 浏览器工具包

扩展兼容 Brave 和 Google Chrome。

## 安装扩展

1. 在目标浏览器打开 `brave://extensions/` 或 `chrome://extensions/`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择 `brave-markdown-reader` 文件夹，并开启“允许访问文件网址”。
4. 复制该浏览器中显示的扩展 ID，写入 `md-launcher\extension-id.txt`。

## 选择浏览器

编辑 `md-launcher\browser.txt`：

- `chrome`：使用 Google Chrome
- `brave`：使用 Brave
- `auto`：优先 Brave，找不到时使用 Chrome

将 `.md` 默认打开方式设置为 `md-launcher\MdLauncher.exe`。扩展 ID 必须来自你在 `browser.txt` 中选择的那个浏览器；Chrome 和 Brave 的扩展 ID 可能不同。

## 编辑模式

打开 Markdown 后点击铅笔按钮进入编辑模式。左侧编辑、右侧实时预览；点击保存按钮或按 `Ctrl+S` 下载 Markdown 副本。
