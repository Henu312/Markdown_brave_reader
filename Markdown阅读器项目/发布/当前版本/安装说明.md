# Markdown 浏览器工具包（当前版本）

当前产品版本：`V2.8.0`。

## 安装扩展

环境要求：Windows 10 或更高版本（64 位）；Chrome、Brave 等 Chromium 浏览器的内核版本 111 或更高。Chrome 可在“设置 - 关于 Chrome”查看版本，Brave 可在 `brave://version` 查看 Chromium 版本。

1. 在 Brave 打开 `brave://extensions/`，或在 Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录中的 `brave-markdown-reader` 文件夹。
5. 开启扩展详情中的“允许访问文件网址”。

## 配置启动器

1. 复制当前浏览器中显示的扩展 ID。
2. 将扩展 ID 写入 `md-launcher\extension-id.txt`。如果两个浏览器使用的扩展 ID 不同，可以按 `brave=你的Brave扩展ID`、`chrome=你的Chrome扩展ID` 分行填写。
3. 在 `md-launcher\browser.txt` 中填写 `brave`、`chrome` 或 `auto`。
4. 将 `.md` 默认打开方式设置为 `md-launcher\MdLauncher.exe`。

说明：`chrome-extension://` 是 Chrome、Brave 等 Chromium 浏览器共用的扩展地址协议，看到这个协议不表示固定使用 Chrome。`browser.txt` 决定实际启动哪个浏览器；修改后无需关闭单实例启动器，下一次打开 Markdown 即会读取新配置。

启动器采用单实例模式：第一次打开创建一个进程，之后打开的 Markdown 文件复用该进程，并在浏览器中创建独立标签页。

## 编辑模式

打开 Markdown 后点击工具栏铅笔按钮进入编辑模式。左侧编辑 Markdown，右侧实时预览；点击保存按钮或按 `Ctrl+S` 下载 Markdown 副本。

在编辑区输入 `<` 可打开 Markdown 语法建议，继续输入 `<image`、`<table`、`<code` 等关键词筛选；使用方向键选择后按 `Enter` 或 `Tab` 插入，也可直接点击。

## 目录结构

- `brave-markdown-reader`：浏览器扩展 V1.2.0，对应产品 V2.8.0。
- `md-launcher`：V2.7.1 单实例 Windows 启动器及配置文件。
- `版本变更记录.md`：完整版本演进记录。
